# SCSE3040 Practical 05 — Configuration and Testing

This repository contains the P05 Jupyter notebook and supporting files for the food-delivery-time regression practical. The work uses YAML configuration, pytest unit tests, and model-behaviour tests.

## Contents
- `P05.ipynb` — walkthrough and completed T1, T2, and T3 task cells.
- `data/delivery_times.csv` — the course's 600-row dataset.
- `work/config.yaml` — data, split, model, and training settings.
- `work/orders.py` — helper functions covered by tests.
- `work/test_orders.py`, `work/test_speed.py` — helper-function tests.
- `work/test_model.py`, `work/conftest.py` — model-behaviour tests and fixtures.

## Run locally
Run commands from the repository root.

```bash
python -m venv .venv
```

Windows PowerShell:
```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m notebook P05.ipynb
```

macOS/Linux:
```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m notebook P05.ipynb
```

Run the tests separately:
```bash
python -m pytest -v work
```

Run the notebook from top to bottom so its cells and outputs are visible. The notebook recreates the config and test files during the walkthrough; rerun the task and self-check cells after the walkthrough.
